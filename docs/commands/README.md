# Command reference

Commands are case-insensitive. Enter `Help` in the application to list registered
commands. Each topic links to command behavior, examples and known limitations.
Rhino's complete command set is still a work in progress.

- [Documents, selection and viewports](document-index.md)

See [command input](../command-line.md) for completion and coordinates,
[viewport controls](../interface.md) for picking and drafting, and
[file formats](../file-formats.md) for import/export support.
